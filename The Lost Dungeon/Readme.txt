# 🏰 THE LOST DUNGEON

A simple text-based adventure game built using Python.

Step into a mysterious dungeon, explore different rooms, discover hidden secrets, collect items and prepare yourself to fight the Undead Knight.

This is one of my beginner Python projects, created to practise programming concepts while building something fun and interactive.

## 🎮 Features

- Explore different paths inside the dungeon.
- Discover hidden rooms and mysterious clues.
- Find potions and collect useful items.
- Explore the witch's diary and uncover secrets about the Moon Key.
- Fight the Undead Knight in a boss battle.
- Choose between attacking, healing and running away.

## 🛠️ Built With

- Python
- `time` module
- Functions
- Loops and conditional statements
- Lists and basic inventory management
- User input and output

## 🚀 How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the `THE-LOST-DUNGEON` folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python dungeon.py
```
