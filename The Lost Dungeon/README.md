THE LOST DUNGEON

A beginner-friendly Python text adventure game where players explore a mysterious dungeon, discover secrets, collect items and fight enemies.

Features

Interactive story-based gameplay

Multiple exploration paths

Potion room and secret room

Inventory system

Hidden Moon Key

Undead Knight boss fight

Attack, Heal and Run combat system

Slow text animation using Python's time module

Technologies Used

Python

Time module

Functions

Lists

Conditional statements

Loops

User input

How to Play

Install Python.

Download or clone this repository.

Open the project folder in VS Code.

Run:

python dungeon.py
